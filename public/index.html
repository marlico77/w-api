Documentação do Sistema e API

Bem-vindo à Documentação Oficial da SAPI API!

Este sistema é uma solução completa para automação de mensagens, gerenciamento de contatos e conexão multidevice com o WhatsApp Web. Siga as orientações abaixo para integrar a API com sistemas externos e gerenciar o fluxo de disparo.

1. Consumo da API (Integração de Sistemas)

Para integrar seu sistema financeiro, ERP ou CRM e enviar mensagens automáticas ou gerenciar chats externamente, você deve primeiro criar um Projeto na aba correspondente do menu para gerar uma Chave de API (Secret) vinculada à instância de WhatsApp correspondente.

Endpoint de Envio de Texto (POST)

https://[SEU_DOMINIO_OU_IP]/api/v1/instances/[NOME_DA_INSTANCIA]/send-text
Endpoints de Chat e Eventos (Construção de Chat Externo)

Se você deseja construir o painel de chat integrado no seu próprio CRM ou sistema externo, estão disponíveis as seguintes rotas autenticadas sob a versão 1 da API:

Método Endpoint Descrição
GET /api/v1/instances/[ID]/chats Lista conversas ativas (nome, última mensagem, avatar, não lidas)
GET /api/v1/instances/[ID]/chats/[CHAT_ID]/messages Histórico recente de mensagens do chat (parâmetro opcional: ?limit=50)
GET /api/v1/instances/[ID]/chats/[CHAT_ID]/avatar Proxy para recuperar a foto de perfil/avatar do contato
GET /api/v1/instances/[ID]/messages/[MESSAGE_ID]/media?chatId=[CHAT_ID] Proxy e download de arquivos de mídia (imagens, áudio, vídeos, documentos)
POST /api/v1/instances/[ID]/send-text Envia mensagem de texto padrão
POST /api/v1/instances/[ID]/send-media Envia mídia (JSON payload com base64 + mimetype, ou link direto em url)
POST /api/v1/instances/[ID]/chats/[CHAT_ID]/seen Marca todas as mensagens da conversa como visualizadas/lidas
DELETE /api/v1/instances/[ID]/chats/[CHAT_ID]/messages/[MESSAGE_ID] Apaga/revoga a mensagem para todos no WhatsApp
GET /api/v1/instances/[ID]/chat-sse?api_key=[SUA_CHAVE] Canal Server-Sent Events (SSE) para escutar e receber mensagens/atualizações em tempo real
Cabeçalhos (Headers) Necessários
  • Content-Type: application/json
  • x-api-key: sk-live-... [Sua Chave de API Gerada] (ou use o header Authorization: Bearer sk-live-...)
Estrutura do Corpo da Requisição (JSON Payload)
{
  "number": "5511999999999", // Número completo: DDI + DDD + Telefone (apenas dígitos)
  "message": "Olá! Esta é uma notificação automática enviada via SAPI API."
}
Exemplos de Implementação de Código

Exemplo cURL (Terminal/Postman)

curl -X POST "https://[SEU_DOMINIO]/api/v1/instances/[INSTANCIA]/send-text" \
  -H "Content-Type: application/json" \
  -H "x-api-key: sk-live-sua-chave-aqui" \
  -d '{
    "number": "5511999999999",
    "message": "Olá de teste!"
  }'

Exemplo Node.js / JavaScript (Fetch)

fetch('https://[SEU_DOMINIO]/api/v1/instances/[INSTANCIA]/send-text', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json',
        'x-api-key': 'sk-live-sua-chave-aqui'
    },
    body: JSON.stringify({
        number: '5511999999999',
        message: 'Olá de teste!'
    })
})
.then(res => res.json())
.then(data => console.log(data));

Exemplo PHP (cURL)

<?php
$curl = curl_init();
curl_setopt_array($curl, [
    CURLOPT_URL => "https://[SEU_DOMINIO]/api/v1/instances/[INSTANCIA]/send-text",
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_CUSTOMREQUEST => "POST",
    CURLOPT_POSTFIELDS => json_encode([
        "number" => "5511999999999",
        "message" => "Olá de teste!"
    ]),
    CURLOPT_HTTPHEADER => [
        "Content-Type: application/json",
        "x-api-key: sk-live-sua-chave-aqui"
    ],
]);
$response = curl_exec($curl);
curl_close($curl);
echo $response;

2. Fila Automática, Anti-Spam e Opt-Out

O módulo de Mensagens Automáticas utiliza um Motor de Fila Nativo operado diretamente pelo seu banco de dados PostgreSQL. Ele garante alta resiliência, tolerância a falhas e total obediência às políticas de envio do WhatsApp, prevenindo o banimento das suas instâncias.

  • 2.1. Sincronização Prévia
    Antes de agendar qualquer disparo, você precisa ir no menu Instâncias Web > Gerenciar e clicar em Importar Contatos. O sistema copiará os seus chats recentes para o banco de dados e os qualificará como contatos aptos (opt_in = 1).
  • 2.2. Throttling (Atraso Anti-Spam Nativo)
    As campanhas não disparam mensagens simultâneas. O nosso Motor de Fila gerencia a carga e impõe um cooldown fixo de 25 segundos entre cada mensagem de uma mesma instância. Se você enviar para 1000 pessoas, o robô respeitará o limite de ~2 mensagens por minuto, mantendo a reputação do seu chip (Quality Rating) sempre verde no algoritmo da Meta.
  • 2.3. Opt-out Automático (Descadastro Imediato)
    Qualquer pessoa da sua base que responder à sua instância com as palavras PARE, SAIR, CANCELAR, STOP ou NÃO QUERO terá sua flag de permissão automaticamente convertida para opt_out = 1. O motor de fila, ao puxar esse contato da tabela, recusará o envio na hora e cancelará a mensagem silenciosamente.
  • 2.4. Circuit Breaker (Quarentena de Instância)
    Se durante uma campanha a sua conexão cair bruscamente, o web-scraper sofrer falha ou a sua conta sofrer denúncias, o sistema detecta o erro "Session Closed" e entra no modo Circuit Breaker. A sua fila de disparos para aquela instância será congelada automaticamente por 10 minutos, impedindo que o sistema entre em loop infinito de tentativas falhas que resultariam em banimento definitivo pela Meta.
  • 2.5. Recorrência Inteligente
    Uma vez agendada como "Recorrente", a campanha finalizará todos os envios. Em vez de simplesmente morrer, ela irá pesquisar na matriz de horários e dias da semana escolhidos por você para se auto-reagendar para o próximo horário disponível, zerando a fila de todos os contatos para um novo disparo de ciclo completo.

3. Gerenciamento de Instâncias e Sessões

As instâncias representam sessões do WhatsApp Web abertas pelo robô.

  • Headless Browser: A API inicia um navegador oculto (Chromium) no servidor do Railway para simular a presença do celular.
  • Persistência: Graças ao volume do Railway montado no caminho `/app/.wwebjs_auth`, os logins permanecem seguros mesmo quando novos commits de código são efetuados na aplicação.
  • Botão Desconectar (Reset): Caso precise trocar o WhatsApp de alguma instância, clique no botão Desconectar. O sistema forçará o fechamento de qualquer navegador ativo, excluirá os dados de login antigos do disco e recriará a instância limpa, fornecendo um novo QR Code na tela instantaneamente.
