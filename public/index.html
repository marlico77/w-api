Documentação do Sistema e API

Consumo da API Externa

O sistema permite que plataformas externas enviem mensagens de texto através das suas instâncias conectadas. Para isso, você deve criar um "Projeto" no menu lateral e gerar uma Chave de API.

Endpoint de Envio de Texto (POST)

http://[SEU_IP_OU_DOMINIO]/api/v1/instances/[ID_DA_INSTANCIA]/send-text
Cabeçalhos Obrigatórios (Headers)
  • Content-Type: application/json
  • x-api-key: sk-live-... [SUA_CHAVE_GERADA] (ou Authorization: Bearer sk-live-...)
Corpo da Requisição (JSON)
{
  "number": "5511999999999",
  "message": "Olá! Esta é uma mensagem de teste enviada pela API."
}

Campanhas Automáticas e Recorrência

No menu de Mensagens Automáticas, você pode programar o envio de mensagens em massa para seus contatos.

  • Base de Contatos: Para uma campanha rodar, primeiro certifique-se de acessar Instâncias Web > Ações > Sincronizar Contatos para baixar a agenda do aparelho.
  • Mensagens Recorrentes: Ao marcar uma campanha como recorrente, o robô automaticamente refaz a fila de contatos quando terminar, aguardando o próximo horário e dia agendados (Ex: "Toda Seg, Qua às 09:00 e 15:00").
  • Proteção Anti-Spam: O sistema possui um intervalo automático de segurança de aproximadamente 37 segundos entre o envio de cada mensagem da fila, evitando bloqueios do WhatsApp.

Instâncias Web

As instâncias representam o seu aparelho celular conectado ao sistema via WhatsApp Web.

  • Para conectar, clique em "Nova Instância", gere um nome, salve e então clique no ícone de QR Code para escaneá-lo com o aplicativo do celular.
  • Atenção: Mantenha o seu aparelho celular conectado à internet. O sistema depende que o WhatsApp do celular consiga sincronizar as mensagens com a rede.
